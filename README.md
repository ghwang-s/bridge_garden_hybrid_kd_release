# The Bridge-Garden Dilemma in LLM Distillation
### Why Mixing Hard and Soft Labels Works

[![OpenReview](https://img.shields.io/badge/OpenReview-ICML%202026-blue)](https://openreview.net/forum?id=oRdJzUD39a)
[![License](https://img.shields.io/badge/License-Apache%202.0-green.svg)](LICENSE)

This repository accompanies the ICML 2026 paper. It provides the Hybrid KD
training and evaluation code used for the LLM distillation experiments, together
with a controlled synthetic study that measures the token-level risk exactly.

## The idea

When a smaller student is distilled from a larger teacher, the target tokens play
two different roles. Some tokens carry latent state that later tokens depend on: a
wrong choice here propagates and compounds as the student generates, an effect
known as exposure bias. We call these high-risk positions bridges, and they need
the exact teacher token, a hard label. Other tokens only vary local wording. We
call these low-risk positions gardens, and they are better served by the full
teacher distribution, a soft label, which transfers more information without
over-committing.

A per-token leave-one-out risk, κ, makes this split precise: it measures how much
the student's future loss grows when the token at a position is perturbed. Hybrid
KD combines a soft teacher-distribution term with a teacher-argmax hard-label term.
The weight on each term can be a single constant or set per token from a teacher
signal, which the paper studies as a family of variants. The bridge-garden
structure is why the combination beats either loss alone: the hard-label term
protects the bridges, the soft-label term informs the gardens.

## Repository layout

- `llm_hybrid_kd/`: Hybrid KD for LLM distillation. TRL trainer extensions (the
  on-policy Hybrid GKD trainer, the soft and on-policy GKD base, and an SFT+KD
  trainer that implements the confidence-, entropy-, curriculum-, and risk-guided
  weighting variants), training entrypoints, launch examples, and an
  AlpacaEval-style judge. Model, data, and output paths are command-line arguments.
- `bridge_garden_v2/`: a controlled synthetic study. Its dialogue, math, and code
  domains are generated by a known finite-state process, so the token-level risk κ
  can be computed exactly by dynamic programming over that process. This lets the
  bridge-garden mechanism be checked on data where the ground truth is known.
  Includes the exact oracle, small teacher/student training, visualization, and
  regression tests.
- `scripts/`: synthetic experiment orchestration, exact-cost and oracle-cost
  checks, manifest building, and readable κ heatmap rendering.

## Installation

Create an environment with Python 3.10 or newer, then install the core
dependencies:

```bash
pip install -r requirements.txt
```

For LLM training, install a TRL version compatible with the trainer files in
`llm_hybrid_kd/trl_trainer/`, or copy these trainer files into the corresponding
`trl.trainer` package in your training environment.

## LLM distillation experiments

All model, data, and output paths are command-line arguments. The launch examples
cover the soft KD baseline, plain SFT, and the on-policy hybrid:

```bash
export STUDENT_MODEL=/path/to/student
export TEACHER_MODEL=/path/to/teacher
export TRAIN_DATA=/path/to/train.jsonl
export OUTPUT_DIR=./outputs/hybrid_gkd
export NUM_GPUS=1

bash llm_hybrid_kd/examples/train_soft_gkd.sh     # soft KD baseline
bash llm_hybrid_kd/examples/train_sft.sh          # supervised fine-tuning
bash llm_hybrid_kd/examples/train_hybrid_gkd.sh   # on-policy hybrid, static weights
```

### Hybrid supervision variants

The weight between the soft (teacher-distribution) and hard (teacher-argmax) terms
can be a constant or set adaptively per token from a teacher signal. The paper
studies a static weighting together with confidence-based, entropy-based,
curriculum, and risk-guided schemes. The adaptive schemes are selected through
`train_sft.py` with `--phi_type`:

```bash
# confidence-based: lower the soft weight where the teacher is confident
python llm_hybrid_kd/train_scripts/train_sft.py --phi_type adap_sft ...

# entropy-based: soft weight follows the teacher's normalized entropy
python llm_hybrid_kd/train_scripts/train_sft.py --phi_type entropy_sft_distill --entropy_gamma 0.1 ...

# curriculum: raise the soft weight on a linear warm-up
python llm_hybrid_kd/train_scripts/train_sft.py --phi_type curriculum_weight --curriculum_warmup_ratio 0.2 ...

# risk-guided: reshape the hard loss with a chi-square objective (reinforcement-learning view)
python llm_hybrid_kd/train_scripts/train_sft.py --phi_type chi2 --alpha 0.05 --gamma 0.9999 ...
```

The soft divergence is chosen with `--div {ab,sfkl,srkl,tv,akl,jsd}`. The on-policy
GKD entry point `train_hybrid_gkd.py` uses static weights `--lambda_fkl` and
`--lambda_sft`.

### AlpacaEval-style judge

The judge utility uses an OpenAI-compatible API.

```bash
export JUDGE_API_KEY=<your_key>
export JUDGE_BASE_URL=https://api.openai.com/v1
export JUDGE_MODEL=gpt-4o-mini
python llm_hybrid_kd/eval/alpacaeval_llm_judge.py \
  --model_outputs outputs/hybrid_gkd/alpaca_eval_outputs.json \
  --baseline text_davinci_001
```

## Controlled synthetic validation

The synthetic study reproduces the bridge-garden mechanism in a setting where κ is
exact. Run the tests:

```bash
python -m pytest bridge_garden_v2/tests -q
```

Inspect the mini pipeline, or run a single domain:

```bash
python scripts/run_synthetic_mini_pipeline.py --help
python -m bridge_garden_v2.run_experiment --domain math --mode smoke
```

The dialogue, math, and code domains support exact token-level κ analysis and
readable heatmap generation.
